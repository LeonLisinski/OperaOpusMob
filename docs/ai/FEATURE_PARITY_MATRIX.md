# Feature Parity Matrix

Prati status migracije po funkcionalnoj cjelini. Ovo je početna matrica s poznatim cjelinama iz `CURRENT_ARCHITECTURE.md` — nije popis svih 757 JSON layout datoteka niti svih tenant varijanti.

Android i iOS su ravnopravne ciljane platforme (v. `TARGET_ARCHITECTURE.md`) — stupac "Testirani tenant" se popunjava po obrascu `tenant (platforma)`, npr. `SVAM (Android)`, i cjelina se ne smije označiti `verified` dok paritet nije potvrđen na obje platforme.

## Statusi

| Status | Značenje |
|---|---|
| `not-analyzed` | Cjelina još nije detaljno analizirana za potrebe migracije |
| `analyzed` | Trenutno ponašanje je dokumentirano, migracija nije počela |
| `planned` | Plan promjene postoji i odobren je |
| `in-progress` | Implementacija u `expo/` je u tijeku |
| `parity-review` | Implementacija postoji, provjerava se funkcionalna jednakost |
| `verified` | Paritet potvrđen na test tenantu — **trenutno se ni jedna cjelina ne nalazi u ovom statusu** |
| `blocked` | Migracija blokirana vanjskim faktorom (npr. otvoreno pitanje) |
